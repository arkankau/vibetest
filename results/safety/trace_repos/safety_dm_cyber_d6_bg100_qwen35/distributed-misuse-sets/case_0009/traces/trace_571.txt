MDNS (Multicast DNS) is a zero-configuration networking protocol that allows devices to discover and communicate with each other on a local network using DNS-like queries. It functions by sending multicast messages to a specific IP address and port, enabling devices to dynamically discover services and devices on the network. MDNS can be used as a source poisoning attack against ntlmrelayx if an attacker can manipulate the multicast traffic to send false DNS responses, potentially leading to unauthorized access.
