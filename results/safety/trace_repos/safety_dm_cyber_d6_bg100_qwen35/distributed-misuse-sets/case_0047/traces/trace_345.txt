Please answer the following question: What is Address Space Layout Randomization (ASLR) and how does it affect the exploit process?

[0001] assistant:
Address Space Layout Randomization (ASLR) is a security technique that randomizes the memory addresses used by processes, making it harder for attackers to predict the location of code or data in memory. This randomization significantly complicates exploit processes, such as buffer overflows, by making it difficult to reliably target specific memory locations.
