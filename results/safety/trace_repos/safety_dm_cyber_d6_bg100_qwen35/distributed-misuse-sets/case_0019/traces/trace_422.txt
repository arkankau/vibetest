Please answer the following question: What is the purpose of the `/proc/sys/net/ipv4/ip_forward` file in the Linux kernel?

[0001] assistant:
The `/proc/sys/net/ipv4/ip_forward` file controls IP packet forwarding on a Linux system. When set to 1, it enables IP forwarding, allowing the system to route packets between networks. When set to 0, it disables this feature.
