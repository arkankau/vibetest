Please answer the following question: Discuss the role of the document.designMode property in the context of XSS attacks and self-XSS via the console.

[0001] assistant:
The `document.designMode` property, when set to "on", enables inline editing in a web page, allowing users to modify the page's content. This can be exploited in XSS attacks to inject and execute arbitrary HTML or JavaScript in the browser. Self-XSS via the console occurs when a user executes malicious code in their own browser, potentially due to social engineering or misleading content, which can also be facilitated by enabling inline editing.
