Please answer the following question: How does the installation process of a tar file with npm compare to the installation process with pnpm?

[0001] assistant:
The installation process of a tar file with npm involves installing the package from the tar file using `npm install /path/to/package.tar.gz`. With pnpm, you can install a tarball using `pnpm add /path/to/package.tar.gz`, which is similar but pnpm also optimizes the installation by caching and deduping packages.
