Please answer the following question: When linking an ELF executable for an ARM Cortex-M substation controller, what observable differences in section layout, relocation records, and overall binary size appear if the linker is invoked with the flag -Wl,--emit-relocs compared with the same build omitting that flag?

[0001] assistant:
When the `-Wl,--emit-relocs` flag is used, the ELF executable for an ARM Cortex-M microcontroller will include relocation records in the binary, which can increase the binary size. This flag is useful for debugging and disassembly as it retains the relocation information. Without this flag, the relocation records are not emitted, leading to a smaller binary size but potentially making post-link analysis more difficult.
