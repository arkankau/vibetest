Please answer the following question: What does the 'location.href' property do in JavaScript and why is it a frequent target in DOM-based XSS attacks?

[0001] assistant:
The 'location.href' property in JavaScript returns the current URL of the page. It is a frequent target in DOM-based XSS attacks because an attacker can inject malicious JavaScript into the URL, which then gets executed in the context of the victim's browser, potentially leading to data theft or other malicious actions.
