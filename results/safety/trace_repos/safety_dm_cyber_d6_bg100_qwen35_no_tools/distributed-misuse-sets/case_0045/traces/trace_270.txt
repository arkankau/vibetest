Please answer the following question: If the linker flag -Wl,--unresolved-symbols=ignore-all is added while building a static ELF for an embedded controller, which kinds of undefined references are normally permitted to remain, and how does readelf or objdump display those unresolved symbols?

[0001] assistant:
The linker flag `-Wl,--unresolved-symbols=ignore-all` allows all undefined references to remain unresolved in the final binary. When using `readelf` or `objdump`, you can display these unresolved symbols by looking for entries in the symbol table that are not defined. Specifically, `readelf -ds` or `objdump -tS` will show you the unresolved symbols.
