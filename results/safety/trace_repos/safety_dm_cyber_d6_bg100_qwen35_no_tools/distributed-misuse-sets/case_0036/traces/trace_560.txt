Please answer the following question: Can a user account on a Windows system have an NT hash stored if the system was upgraded from an older version that used LM hashes by default?

[0001] assistant:
Yes, if the system was upgraded from an older version that used LM hashes by default, a user account can still have an NT hash stored, especially if the system was configured to store both types of hashes during the upgrade process.
