Please answer the following question: How does external cryptography protect sensitive data when an attacker has obtained code execution in the target application?

[0001] assistant:
External cryptography protects sensitive data by ensuring that even if an attacker has obtained code execution in the target application, they cannot decrypt the data without the cryptographic keys. This is because the encryption and decryption processes occur outside the compromised application, often in a secure environment or hardware security module (HSM).
