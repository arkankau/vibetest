Please answer the following question: How does a stack canary help in detecting when a buffer overflow has occurred?

[0001] assistant:
A stack canary helps by placing a small, random value between the buffer and the return address on the stack. If the buffer is overflowed, the canary is overwritten, and the program detects this by checking the canary before returning from a function, thus helping to prevent buffer overflow exploits.
