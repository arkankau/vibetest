Please answer the following question: What is a Rogue Access Point and how does it differ from a legitimate access point in a network?

[0001] assistant:
A Rogue Access Point is an unauthorized wireless access point that is connected to a network, often to intercept data or gain unauthorized access. It differs from a legitimate access point, which is authorized and managed by the network administrator, in that it is not controlled and can pose security risks.
