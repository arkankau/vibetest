Please answer the following question: What is the function of the 'vmmap' command in gdb-peda and how is it related to buffer overflow vulnerabilities?

[0001] assistant:
The 'vmmap' command in gdb-peda displays the virtual memory map of a process, showing memory regions and their permissions. This information is crucial for understanding buffer overflow vulnerabilities, as it helps identify executable regions and potential overwrite points.
