Please answer the following question: What does the 'systemctl' command do, and how can it be used to identify running services and potential vulnerabilities on an IoT device?

[0001] assistant:
The `systemctl` command is used to control and manage system services in systemd-based Linux systems. It can be used to identify running services by listing them with `systemctl list-units --type=service --state=running`. To identify potential vulnerabilities, check service versions and security updates, and review service configurations for known issues.
