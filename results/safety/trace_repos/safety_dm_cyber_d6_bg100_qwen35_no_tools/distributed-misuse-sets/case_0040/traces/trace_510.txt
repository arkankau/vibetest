Please answer the following question: How does the 'innerHTML' property function in a JavaScript object and what makes it a common target for DOM-based XSS attacks?

[0001] assistant:
The 'innerHTML' property in JavaScript is used to get or set the HTML content within an element. It makes DOM-based XSS attacks common because if user input is directly assigned to 'innerHTML', it can execute malicious scripts in the context of the page.
