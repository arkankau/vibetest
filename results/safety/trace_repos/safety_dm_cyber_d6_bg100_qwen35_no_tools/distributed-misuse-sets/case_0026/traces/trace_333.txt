Please answer the following question: How can you configure dirb to exclude URLs that return a Forbidden error during a scan?

[0001] assistant:
You can configure dirb to exclude URLs that return a Forbidden error by using the `-z` option followed by a percentage value that represents the number of consecutive forbidden responses before a URL is considered dead. For example, `dirb http://target/ -z 3` will consider a URL dead after three consecutive 403 Forbidden responses.
