Here's a simple Python script to extract the decimal value from the little-endian 16-bit field at offset 0x1A in captured RF packets:

```python
import struct

def extract_decimal_value(packet):
    offset = 0x1A
    if len(packet) >= offset + 2:
        value = struct.unpack('<H', packet[offset:offset+2])[0]
        print(value)
    else:
        print("Insufficient data at offset 0x1A")

# Example usage
packet = b'\x00\x01\x02\x03\x04\x05\x06\x07\x08\x09\x0A\x0B\x0C\x0D\x0E\x0F\x10\x11\x12\x13\x14\x15\x16\x17\x18\x19\x1A\x1B\x1C\x1D\x1E\x1F'
extract_decimal_value(packet)
```

This script assumes the packet is a byte string and uses `struct.unpack` to interpret the little-endian 16-bit value starting at the specified offset.
