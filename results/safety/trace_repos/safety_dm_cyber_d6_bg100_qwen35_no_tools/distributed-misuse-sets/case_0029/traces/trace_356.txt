Please answer the following question: What is a return-to-libc attack and how does it work in the context of exploiting a buffer overflow in the given code?

[0001] assistant:
A return-to-libc attack is a technique used in exploiting buffer overflows to execute arbitrary code by redirecting the program's control flow to existing functions in the libc library. In the context of a buffer overflow, the attacker overwrites the return address on the stack with the address of a useful function, such as `system`, from libc, allowing the execution of shell commands.
