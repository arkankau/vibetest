Please answer the following question: What is the LNK vulnerability and how can it be exploited to spread malware via removable media?

[0001] assistant:
The LNK vulnerability, also known as the "Windows Link Vulnerability," allows attackers to spread malware through malicious .LNK files on removable media. When a user double-clicks such a file, it can execute arbitrary code, leading to malware infection without the user needing to run an executable explicitly.
