Please answer the following question: How does automated unit testing of software libraries differ from fuzzing and what are its main purposes?

[0001] assistant:
Automated unit testing of software libraries involves running predefined tests to verify that individual units of code work as expected, while fuzzing involves feeding random or unexpected data to the software to test its robustness and detect crashes or bugs. The main purposes of automated unit testing are to ensure correctness, reliability, and maintainability of the code, whereas fuzzing aims to uncover edge cases and security vulnerabilities.
