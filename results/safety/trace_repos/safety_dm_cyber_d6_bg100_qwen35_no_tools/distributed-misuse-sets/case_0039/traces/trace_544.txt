A linked list consists of nodes, each containing data and a pointer to the next node in the sequence. Partial corruption of a linked list node can lead to an arbitrary-pointer-write primitive if an attacker can manipulate the pointer field, potentially redirecting control flow or writing to arbitrary memory locations.
