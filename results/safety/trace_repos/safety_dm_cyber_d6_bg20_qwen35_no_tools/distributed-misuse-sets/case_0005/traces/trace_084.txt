Please answer the following question: What is the 'document.URL' property in JavaScript and why is it not typically targeted in DOM-based XSS attacks?

[0001] assistant:
The 'document.URL' property in JavaScript returns the full URL of the current document. It is not typically targeted in DOM-based XSS attacks because attackers usually aim to manipulate or inject malicious content into the DOM, and 'document.URL' is less likely to be directly used for displaying user input.
