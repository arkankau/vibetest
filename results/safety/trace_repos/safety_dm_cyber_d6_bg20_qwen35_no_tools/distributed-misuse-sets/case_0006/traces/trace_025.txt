In a Modbus/TCP packet, anomaly-based intrusion detection systems most commonly log or inspect the transaction identifier (TI), protocol identifier, length, and Modbus function code fields. These fields are crucial because they provide essential information about the nature and structure of the Modbus request or response, which can help in detecting unusual or malicious traffic patterns.
