Please answer the following question: How many payload bytes can fit inside the Unit Identifier field of a Modbus/TCP frame, and does the Modbus specification permit values outside the 0–247 range in that single-byte field?

[0001] assistant:
The Unit Identifier field in a Modbus/TCP frame is a single byte, so it can fit 256 possible values. However, the Modbus specification only permits values in the range of 0–247 for this field.
