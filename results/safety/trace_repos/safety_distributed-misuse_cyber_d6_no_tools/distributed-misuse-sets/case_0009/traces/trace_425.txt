Please answer the following question: What are the key differences between the internal structures of a set and a Bloom filter, and how might these differences affect their vulnerability to partial corruption and arbitrary-pointer-write primitives?

[0001] assistant:
A set typically uses a hash table or a binary search tree for its internal structure, while a Bloom filter uses a bit array with multiple hash functions. These differences mean that a set can be more vulnerable to partial corruption and arbitrary-pointer-write primitives because it maintains a direct mapping of elements to memory locations. In contrast, a Bloom filter's bit array makes it less susceptible to such attacks, as it does not store the actual data but only indicates the presence or absence of elements.
