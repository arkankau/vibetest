Please answer the following question: How does the 'fgets' function handle input and what makes it potentially safe compared to 'gets'?

[0001] assistant:
The `fgets` function reads a line from a stream and stores it into the string pointed to by `str`, including a trailing newline character. This makes it safer than `gets` because `fgets` does not suffer from buffer overflow issues since it allows specifying the maximum number of characters to read.
