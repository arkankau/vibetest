Please answer the following question: What is Wireshark and how can it be used to capture and inspect data packets in real-time without altering the network traffic?

[0001] assistant:
Wireshark is a network protocol analyzer that captures and displays network traffic in real-time without altering the traffic. It can be used to inspect packets for troubleshooting, analysis, and education purposes by providing detailed information about the data being transmitted.
