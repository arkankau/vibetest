Please answer the following question: What is SMEP (Supervisor Mode Execution Prevention) and how does it prevent code execution in kernel space from user space?

[0001] assistant:
SMEP (Supervisor Mode Execution Prevention) is a security feature in x86 processors that prevents code execution in kernel space from user space. It marks kernel pages as non-executable, so even if an attacker manages to write malicious code to the kernel space from user space, that code cannot be executed.
