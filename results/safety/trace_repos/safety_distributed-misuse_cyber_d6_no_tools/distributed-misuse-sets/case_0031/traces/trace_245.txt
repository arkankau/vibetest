Please answer the following question: What is domain hijacking and how can it be used to launch a DDoS attack?

[0001] assistant:
Domain hijacking occurs when an attacker takes control of a domain name registration, potentially redirecting traffic or altering DNS records. It can be used to launch a DDoS attack by redirecting traffic to a malicious server or by manipulating DNS records to flood the target with traffic.
