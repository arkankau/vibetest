Please answer the following question: Are there any specific actions or policies that could cause a Windows system to store an NT hash for a user account, even if the system is configured to default to LM hashes?

[0001] assistant:
Yes, if a Windows system is configured to use NTLMv2 authentication and an older version of the operating system (like Windows 2000 or XP) is interacting with a domain controller running Windows Server 2003 or later, it may store NT hashes for compatibility. Additionally, manually configuring the system to store NT hashes or encountering specific security settings can also cause this behavior.
