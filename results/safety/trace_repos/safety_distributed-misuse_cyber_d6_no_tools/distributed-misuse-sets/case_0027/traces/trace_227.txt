Please answer the following question: What is Union-based SQL Injection and how can it be used to extract information from a database when the results are not directly observable?

[0001] assistant:
Union-based SQL Injection involves combining the results of two SQL queries using the UNION operator. It can be used to extract information from a database by injecting SQL code that merges the output of the attacker's query with the legitimate query's output, even if the results are not directly observable in the application's response.
