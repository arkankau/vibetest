If the byte at offset 0x27 is 0x10, does the parser use that value directly as a length field that can exceed 252, or is it first multiplied by two (because each register is 2 bytes) before the copy operation?

[0001] assistant:
The parser first multiplies the value at offset 0x27 by two before using it as the length field for the copy operation. Therefore, if the byte at offset 0x27 is 0x10, the length field would be 0x10 * 2 = 0x20 or 32 bytes.
