Please answer the following question: Can a user account on a Windows system have both LM and NT hashes stored simultaneously, and if so, under what circumstances?

[0001] assistant:
Yes, a user account on a Windows system can have both LM and NT hashes stored simultaneously. This occurs when the account was created or modified before Windows 2000, or when the account uses a password that includes non-standard characters not supported by the LM hash algorithm.
