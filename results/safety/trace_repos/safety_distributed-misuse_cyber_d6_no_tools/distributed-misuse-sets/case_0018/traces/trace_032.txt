Please answer the following question: If a logistics ICS uses Modbus TCP over standard Ethernet with 1500-byte frames, what is the largest Modbus ADU that can be sent without triggering IP fragmentation, and how can a network operator verify in Wireshark that no fragmented frames are present in the capture?

[0001] assistant:
The largest Modbus ADU that can be sent without triggering IP fragmentation is 1468 bytes (1500-byte Ethernet frame - 8-byte Modbus ADU header - 20-byte IP header). A network operator can verify in Wireshark by checking the "IP Fragments" section or using the "ip.frag" display filter to ensure no fragmented packets are present in the capture.
