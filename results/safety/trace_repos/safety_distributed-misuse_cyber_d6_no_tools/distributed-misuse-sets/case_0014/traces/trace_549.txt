Please answer the following question: What is the role of Windows PatchGuard and how might an attacker need to invalidate it?

[0001] assistant:
Windows PatchGuard is a security feature that prevents unauthorized modification of the Windows kernel, helping to maintain system stability and security. An attacker might need to invalidate PatchGuard to install malicious drivers or modify system code, though this can lead to system instability and is generally detected and blocked by modern security measures.
