Please answer the following question: How does reverse genetics simplify the process of introducing specific mutations into a viral genome compared to traditional genetic techniques?

[0001] assistant:
Reverse genetics allows for the direct introduction and verification of specific mutations in a viral genome by using cDNA, which is then used to generate infectious viral particles. This approach simplifies the process compared to traditional techniques because it bypasses the need to first generate and then screen numerous mutants, directly linking genetic changes to phenotypic outcomes.
