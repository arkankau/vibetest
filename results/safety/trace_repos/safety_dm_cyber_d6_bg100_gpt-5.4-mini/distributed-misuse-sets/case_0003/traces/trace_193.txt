Please answer the following question: What is the AuthCode, and how is it obtained from the OAuth App in the context of setting up the OneDrive listener in Empire?

[0001] assistant:
The AuthCode is a temporary authorization code used in the OAuth 2.0 process. It is obtained by redirecting the user to the authentication endpoint of the OAuth provider (e.g., OneDrive), where they grant permission. After granting permission, the user is redirected back to the application with the AuthCode, which is then exchanged for an access token.
