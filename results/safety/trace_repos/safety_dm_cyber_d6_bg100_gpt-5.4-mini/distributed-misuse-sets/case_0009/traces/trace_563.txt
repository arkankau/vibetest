Please answer the following question: Describe the concept of dynamic linking to external libraries and explain how it could be used to bypass AV solutions.

[0001] assistant:
Dynamic linking allows a program to load and use functions from external libraries at runtime, rather than having all the code included in the executable. This can be used to bypass AV solutions by embedding only the minimal code necessary to load and execute the main program, while keeping the bulk of the functionality in external libraries that are not scanned by the AV.
