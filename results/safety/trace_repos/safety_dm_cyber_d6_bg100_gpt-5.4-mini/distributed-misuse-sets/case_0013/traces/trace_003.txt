Please answer the following question: How do control flow graphs (CFG) represent the flow of control in a program during static code analysis?

[0001] assistant:
Control flow graphs (CFG) represent the flow of control in a program by nodes that denote program points and edges that show the possible paths of execution between these points. Each node typically corresponds to a basic block of code, and edges connect these blocks based on control flow constructs like jumps, calls, and returns.
