Please answer the following question: If a Modbus TCP/IP message is split into two Ethernet frames at the exact midpoint of the Modbus PDU, which bits in the TCP ‘flags’ field and which values in the Modbus length byte must be adjusted so that the slave reassembles the fragments without dropping the connection?

[0001] assistant:
The TCP 'flags' field does not need to be adjusted. The Modbus length byte must be set to the correct length of the combined message. The slave will reassemble the fragments based on the TCP sequence numbers and the Modbus length byte.
