Yes, the Linux ELF format supports the compilation of binaries as Position-Independent Executables (PIEs). This can be achieved by using the `-fPIE` compiler flag and linking with the `-pie` option. PIEs are typically used to enhance security features like ASLR (Address Space Layout Randomization).
