Please answer the following question: In what scenarios is Time-based SQL injection effective, and what kind of data can it extract?

[0001] assistant:
Time-based SQL injection is effective when the application uses slow database functions or when the database server is not optimized, causing queries to time out. It can extract various types of data, including sensitive information like user credentials, personal details, and financial data, by making the database wait for a specific amount of time to confirm the correctness of a condition in the injected SQL query.
