Please answer the following question: In the C# code 'string path = Path.Combine(Server.MapPath("~/UploadedFiles/"), file.FileName); file.SaveAs(path);', what security problems arise from concatenating the user-supplied file.FileName directly into the final path, and how do different browsers encode filenames like '../web.config' or 'file.aspx%00.pdf'?

[0001] assistant:
Concatenating user-supplied `file.FileName` directly into the path can lead to directory traversal attacks, allowing an attacker to access or modify sensitive files like `web.config` or `file.aspx`. Different browsers encode filenames differently; for example, `../web.config` might be sent as is, while `file.aspx%00.pdf` uses URL encoding to bypass some basic checks, but still allows path traversal.
