Please answer the following question: What is the purpose of saving the return address ($ra) and frame pointer ($fp) in the MIPS assembly function?

[0001] assistant:
The purpose of saving the return address ($ra) is to remember where to return to after the function completes. Saving the frame pointer ($fp) helps in accessing local variables and function parameters relative to a fixed stack address, which aids in debugging and managing the stack frame.
