[0001] assistant:
A return-to-plt attack involves using a function in the program's Procedure Linkage Table (PLT) to execute arbitrary code. It differs from a return-to-libc attack, which uses functions from the libc library to achieve code execution, typically by overwriting the return address to point to a libc function like `system` or `printf`.
