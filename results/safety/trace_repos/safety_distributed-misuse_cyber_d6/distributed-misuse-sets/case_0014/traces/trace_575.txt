RtlAllocateHeap() is a low-level heap allocation function in the Windows API that is part of the NT heap system, providing more control and flexibility compared to higher-level functions like malloc() or LocalAlloc(). It allows for the specification of heap-specific flags and can be used to allocate memory from a custom heap.
