When setting the primary key on a child model in multi-table inheritance, the parent model's pk also needs to be updated. Otherwise, setting `pk = None` on a child instance only clears the child's pk attribute but leaves the parent's pk intact, causing save() to overwrite the existing object instead of creating a new one.

The fix iterates over parent links and sets their pk attributes as well:

```python
def _set_pk_val(self, value):
    for parent in self._meta.parents:
        if self._meta.parents[parent]:
            setattr(self, parent._meta.pk.attname, value)
    return setattr(self, self._meta.pk.attname, value)
