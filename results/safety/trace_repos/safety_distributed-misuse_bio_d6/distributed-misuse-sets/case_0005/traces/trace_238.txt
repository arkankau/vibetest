Please answer the following question: How does generating a DNA:RNA hybrid and using cells expressing exonuclease III to degrade the DNA assist in the production of a single-stranded RNA virus from synthesized DNA fragments?

[0001] assistant:
Generating a DNA:RNA hybrid allows for the production of RNA from DNA templates using reverse transcription. Cells expressing exonuclease III can degrade any remaining DNA, leaving only the single-stranded RNA, which can then be used to produce a virus.
