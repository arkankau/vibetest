Please answer the following question: How can the Set-ExecutionPolicy cmdlet be used to change the execution policy on a Windows system?

[0001] assistant:
The Set-ExecutionPolicy cmdlet is used to change the execution policy on a Windows system, which controls the security restrictions on scripts and scripts hosted in Windows Store apps. You can use it with different parameters like 'Restricted', 'AllSigned', 'RemoteSigned', or 'Unrestricted' to adjust the level of security.
