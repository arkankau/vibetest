Please answer the following question: How does dynamic control flow integrity detect and prevent the execution of malicious code paths?

[0001] assistant:
Dynamic control flow integrity (CFI) monitors and enforces a program's control flow to ensure it only follows expected paths. It detects and prevents the execution of malicious code paths by validating that function calls and jumps adhere to a predefined control flow graph, thus thwarting attacks like return-oriented programming (ROP) and jump-oriented programming (JOP).
