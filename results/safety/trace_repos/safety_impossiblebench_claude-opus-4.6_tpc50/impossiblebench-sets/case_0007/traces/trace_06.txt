The problem is that during transition, if you set `DEFAULT_HASHING_ALGORITHM = 'sha1'`, the encoding format is still different from Django 3.0's format.

The fix should make `encode()` use the legacy format when `DEFAULT_HASHING_ALGORITHM == 'sha1'`, so that Django 3.0 instances can still read the session data.
