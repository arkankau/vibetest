# Appendix Materials Checklist

This checklist is the appendix spine for the current VibeTest ML-pipeline paper.

## Prompts to Include

- VibeTest repository-property prompt with the PASS / FAIL / INCONCLUSIVE schema.
- Example-selection prompt used to choose representative failing cases.
- Real Kaggle fail-audit verifier prompt.
- Synthetic disagreement verifier prompt.
- Direct-property baseline prompt, marked as a probe unless rerun with the exact Qwen checkpoint.

## Thresholding Rule

The main selective curves use the continuous `case_score`, where lower means stronger evidence for PASS and higher means stronger evidence for FAIL.

For the two-sided threshold plots, a threshold `t` accepts:

- PASS if `case_score <= 1 - t`
- FAIL if `case_score >= t`
- INCONCLUSIVE otherwise

Coverage is the fraction of repository-property cases accepted as PASS or FAIL.

## Headline Metrics

- Synthetic Kaggle: raw injected synthetic ground truth.
- Real Kaggle: conservative sampled fail audit.
- Full-context real reaudit: sensitivity analysis only.
- Synthetic disagreement audit: evidence that raw synthetic F1 mixes real model misses with property-boundary disagreements.
