# Reference Style Notes

Reference context:

- `NeurIPS-2025-once-upon-an-input-reasoning-via-per-instance-program-synthesis-Paper-Conference.pdf`
- `NeurIPS-2025-once-upon-an-input-reasoning-via-per-instance-program-synthesis-Bibtex.bib`
- `NeurIPS-2025-once-upon-an-input-reasoning-via-per-instance-program-synthesis-Supplemental-Conference.zip`

How the new VibeTest rewrite uses the reference:

- Lead with the problem/challenge before the system details.
- Put an overview figure early, before the full method section.
- Use compact challenge paragraphs rather than only broad motivation.
- Keep the method section procedural and readable.
- Frame experiments around research questions.
- Keep headline results in one compact table, then explain plots.
- Treat appendices/supporting docs as artifact inventory rather than overloading the main paper.

Important boundary:

The rewrite follows these presentation choices but does not copy the reference paper's prose.
